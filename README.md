# 文曲星模拟器资源目录

提供按机型和运行环境分类的资源索引、授权说明及分发维护工具。资源增补与安卓应用发布独立。

部分历史资源尚未核实再分发授权，已在条目中明确标注；维护者决定先行公开不等于取得作者许可。第三方资源的权利归各自权利人所有，本仓库的工具和文档许可不适用于这些资源。请先阅读[免责声明](docs/DISCLAIMER.md)。如有侵权，可通过[版权投诉入口](https://github.com/xtulnx/wqx-resources/issues/new?template=copyright.yml)请求暂停或删除。

## 资源分类

- **固件**：按机型分类，NC2000 / NC2600 的第三方内核单独归档，区分 ROM、NOR、NAND 文件角色。
- **BIN 程序**：按目录中明确标注的机型分类。
- **BASIC 程序**：按机型或 GvBasic 运行环境分类。
- **LAVA 程序**：按机型或 LAVA 运行环境分类，并注明解释器要求。

运行环境分类不表示兼容所有机型。无法判断用途或目标环境的资源不收录；下载和导入前请核对资源的兼容性说明。

## 分层目录

`catalog.json` 是轻量入口，依次引用“类型 → 机型／运行环境 → 分页索引 → 单个资源说明”。每页最多 25 个资源引用，客户端可按需读取。文件摘要、下载地址、许可和兼容性均放在单独的资源说明中。

资源可包含简介、Logo 和截图，全部使用相对于仓库根目录的路径。维护者按条目保存审核记录；允许覆盖更新和撤回过期资源，覆盖时同步更新文件大小和摘要。资源附件优先通过 Release 分发。固件包不能自动覆盖设备正在使用的可写镜像或用户存档。
