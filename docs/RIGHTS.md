# 权利、免责声明与投诉处理

## 权利边界

本项目用于整理、校验及索引依法可以分发的资源，不代表文曲星厂商或其他资源作者。机型名称用于描述兼容性，不表示官方认可。

文件年代久远、免费提供、已停售、从真机提取、存在于其他公开网站，均不足以单独证明再分发许可。拥有硬件或软件复制品不自动取得面向公众的分发权。固件内可能同时包含系统、词典、字库、游戏等不同权利人的内容。

优先收录有可核实授权基础的资源。历史资源如由维护者决定在授权未确认时先行公开，必须如实标注 unverified，不得填写虚假的授权依据；声明见 [DISCLAIMER.md](DISCLAIMER.md)。已知明确禁止转载的资源不以此流程规避其限制。作者授权仅覆盖其有权授权的内容，不当然覆盖衍生作品中第三方素材。

“仅供学习”“禁止商用”“下载后删除”等声明不能替代授权。本页也不构成免责承诺或对个别文件合法性的法律结论。

## 使用说明

维护者尽力记录来源、许可、兼容性及摘要，但不保证资源适用于所有设备和固件。使用者应先备份数据；资源可能包含历史缺陷。以上说明不排除依法不得免除的责任。

禁止上传通讯录、个人名片、账户信息、私人存档或包含这些信息的可写镜像。授权原件如含联系方式，应本地保存，公开授权说明应取得适当许可并脱敏。

## 权利人联系和撤回

通过仓库 Issue 报告一般问题；不要在公开 Issue 上传个人证件或敏感材料。维护者应在开放下载前提供可用的私密版权联系渠道。

投诉建议包括资源 ID、文件摘要、原作或权利证明链接、争议内容及期望处理方式。维护者收到可信争议后先暂停目录推荐和后续下载，保留必要审核记录，再核实授权范围。

撤回须同时检查公开目录、Release 附件和仍可访问的历史分发位置；仅从最新目录隐藏并不等于撤销已有公开下载。不得删除用户自己的设备工作副本或存档。误上传敏感内容需按平台流程处置，必要时清理历史，不能只做普通删除提交。
